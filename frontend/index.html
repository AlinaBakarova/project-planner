    Project Planner

    Документация

    Обзор

    Project Planner — серверный движок интеллектуального планирования задач и ресурсов.

    Модель ресурсов

    • Человек (human) — возобновляемый ресурс. Может работать над задачей, после завершения — освобождается.
    • Оборудование (machine) — возобновляемый ресурс. После завершения задачи — освобождается.
    • Материал (material) — расходуемый ресурс. Количество уменьшается при использовании. Не восстанавливается.

    Модель задач

    • Задача имеет название и длительность (в минутах).
    • Задача может зависеть от других задач (precedence constraints).
    • Задача B не может начаться до завершения задачи A.
    • Задача может требовать несколько ресурсов с указанием количества.

    Планирование

    • План строится с учётом зависимостей, ресурсов и длительности.
    • Если план построить невозможно — отображается граф конфликтов.
    • Пересчёт плана происходит автоматически при изменении задач или ресурсов.

    Ограничения

    • Нельзя удалить ресурс, если он используется в задачах.
    • Нельзя создать задачу, если запрошено больше ресурса, чем доступно.
    • При удалении задачи — её зависимости автоматически удаляются.
